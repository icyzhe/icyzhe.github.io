# Zhe He's Personal Website

Source for [icyzhe.github.io](https://icyzhe.github.io/).

The site uses static HTML and CSS. Edit `index.html` for page content,
`stylesheet.css` for styles, and `images/` for images.

To preview locally, run from this directory:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Then open <http://127.0.0.1:8000>.
